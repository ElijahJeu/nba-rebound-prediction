# nba-rebound-prediction
NBA Rebound Prediction & Analysis

A data science project analyzing NBA team and player rebounding using historical game data. The goal is to identify which factors have the strongest influence on rebounding and use those factors to build machine learning models that predict future rebounding performance.

The project will explore factors such as minutes played, missed shots, field goal attempts, opponent statistics, recent rebounding performance, pace, and other team and player statistics.

The project will use NBA data collected through the nba_api Python library. Decision trees and other machine learning methods will be used to analyze feature importance and determine which variables are most useful for predicting rebounds.

The project may also be applied to NBA player prop lines to compare model predictions with expected rebound totals, while focusing primarily on sports analytics and model evaluation.
